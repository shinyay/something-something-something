GitHub Copilot App v1.1.4 ハンズオンGitHub Copilot App v1.1.4 hands-on

同じ25個の実践ラボを、成果を横断する6つのジャーニーと、領域を深掘りする10のトラックの両方から進められます。アカウントやバックエンドなしで、進捗はこのブラウザーだけに保存されます。Reach the same 25 hands-on labs through six outcome-spanning journeys or ten domain-deep tracks. Progress is saved only in this browser, with no account or backend.

Horizontal · outcome-spanning

6つのジャーニー6 journeys

1つの成果を最初から最後まで到達するために、複数のトラックを横断してラボを並べたルートです。Ordered routes across multiple tracks that carry one outcome from start to finish.

1

導入から最初の検証済みPRまでInstall to first verified PR

アプリを導入し、最初のセッションを実行してから必要に応じてモデルを調整し、My WorkのIssueをレビュー済みPRとして着地させます。完了時には検証済みPRと片付いたsessionが残ります。Install the app, run a first session, optionally tune models, and land a My Work issue as a reviewed pull request. You finish with a verified PR and a cleaned-up session.

  1. 01 インストールとプロジェクト接続Install and connect projects
  2. 03 セッションを開始してモードを選ぶStart a session and choose a mode
  3. 02 モデル、Auto、BYOK を構成するConfigure models, Auto, and BYOK 任意Optional
  4. 11 My Work のセクションとフィルターを使いこなすMaster My Work sections and filters
  5. 12 Issue のセッションコンテキストと安全なディープリンクIssue session context and safe deep links
  6. 13 プルリクエストレビューを完了するComplete a pull request review
  7. 25 キャップストーン: Issueから検証済みPRの着地と運用クリーンアップまでCapstone: from issue to a verified, landed PR with operational cleanup
2

worktreeとSession Gridによる並列マルチセッション配信Parallel multi-session delivery with worktrees

worktreeで分離した複数sessionをSession Gridで監督し、Files、nested sessions、/side、handoffを段階的に加えます。完了時には衝突しない並列streamと復旧可能な引き継ぎが残ります。Supervise worktree-isolated sessions in Session Grid, then add Files, nested sessions, /side, and handoffs progressively. You finish with non-conflicting delivery streams and a recoverable handoff.

  1. 04 Worktree とローカルリポジトリで並列セッションを実行Run parallel sessions with worktrees and the local repository
  2. 06 Session Grid とサイドチャットで複数セッションを俯瞰するOversee multiple sessions with Session Grid and side chats
  3. 09 ファイル・差分・ブラウザプレビュー・プレゼンテーションモードFiles, diffs, browser preview, and Present mode
  4. 05 オーケストレーションとネストされたセッションOrchestration and nested sessions
  5. 07 チャットのアーカイブ・巻き戻し・コンパクト化Archive, rewind, and compact chats
  6. 08 クラウド・WSL・VS Code・CLIへのハンドオフHand off across cloud, WSL, VS Code, and CLI

Issueからstacked PR配信までIssue-to-stacked-PR delivery

You finish able to explain the issue and stacked-PR state transitions.
