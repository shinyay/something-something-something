Models & environments

Auto と CreditsAuto and credits

Auto はタスクの複雑さと利用可能なモデルに基づいて選択し、完了応答に実モデル、AI Credits、利用可能な cache details を表示します。公式文書では App の Auto は GA で、有料プランのモデルコストに 10% 割引があります。Auto selects from available models based on task complexity and shows the actual model, AI Credits, and available cache details on completed responses. Official docs mark Auto in the app as GA and describe a 10% model-cost discount on paid plans.

推論量と cache boundaryReasoning and cache boundaries

複雑さに合わせて推論量を選びます。model、reasoning effort、context size、enabled tools / MCP の途中変更は cache を無効化し得るため、変更通知で以前のモデルと再利用コンテキストを確認します。Match reasoning effort to complexity. Mid-session changes to model, reasoning effort, context size, or enabled tools/MCP can invalidate cache, so inspect the model-change notice for the prior model and reused context.

WSL remote 環境は Windows 側の App から扱います。v1.1.4 の Windows integrated terminal は PowerShell profile の PATH / 環境変更を反映しますが、これは WSL と同一の実行境界ではありません。Use WSL remote environments from the Windows app. In v1.1.4, Windows integrated terminals pick up PATH and environment changes from the PowerShell profile, but that is not the same execution boundary as WSL.

Scope discipline

App リリースと隣接機能を区別するDistinguish App releases from adjacent capabilities

Copilot CLI, SDK, cloud agent, and sandbox capabilities are scoped through their own official documentation, even when they integrate with the App, and are not attributed to an App release without changelog support.
