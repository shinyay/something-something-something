# GitHub Copilot入門 — 基本とAgenticな使い方

GitとGitHubの基本を知っている方向けに、Copilotの基本とAgenticな使い方を説明する、日本語のHTMLスライドと詳細ガイドです。スライドは本編20枚と補足4枚、詳細ガイドは各スライドに対応する24章で構成します。情報の基準日は2026-10-06、テーマはPrimaryです。既存の [Copilot入門ガイド](../copilot-beginner-guide/) はそのまま残しています。

**既存のスライド公開URL**：
https://shinyay.github.io/something-something-something/copilot-beginner-agentic/

**詳細ガイドの公開予定URL（追加PRのマージとGitHub Pagesへの反映後）**：
https://shinyay.github.io/something-something-something/copilot-beginner-agentic/document.html

リポジトリ内では [スライド](./index.html) と [詳細ガイド](./document.html) を参照できます。詳細ガイドでは、補完・対話の基本に加え、Agenticな依頼、計画、権限、差分と検証、PRレビューを掘り下げています。仮想のタスク一覧アプリ、依頼文、計画、コード例は学習用の例であり、実際のCopilot応答やアプリの修正記録ではありません。

## 保存内容と公開範囲

| ファイル | 内容 |
| --- | --- |
| `index.html` | `presentation.html` と全バイトが同じ別名コピー。既存のスライドURLを維持 |
| `presentation.html` | 資料ペアの標準ファイル名のスライド。対応する詳細ガイドの章へのリンクを含む |
| `document.html` | 各スライドに対応する24章の詳細ガイド。目次、比較表、コード例、図、スライドへのリンクを含む |
| `source\artifact.json` | 文書24章とスライド24枚、24組の対応、公開ノート24件、公式出典9件、図4種類の共通入力 |
| `source\content.ja.html` | 元のスライド本文と、新しい詳細解説の日本語本文 |

各HTMLはフォント、CSS、JavaScript、SVG、素材の原文ライセンス3件を内包します。関連リンクは標準ファイル名を使うため、`document.html` と `presentation.html` を同じフォルダーに置いてください。`index.html` は別のスライド版やリダイレクトではありません。

話者ノートは秘密の発表者用領域ではなく、HTMLと一緒に共有されます。折りたたみ、図の説明、入力2ファイルも公開対象で、既存のPages設定ではURLから取得できます。内部情報や個人情報を追記しないでください。

閲覧時に外部の実行資源を取得する必要はありません。出典リンクを開くときは、リンク先の外部サイトへ移動します。

## 操作方法

| 操作 | 使い方 |
| --- | --- |
| 前後移動 | 「前へ」「次へ」、左右矢印、PageUp／PageDown。Home／Endは現在の本編・補足の先頭・末尾へ移動 |
| スライド一覧 | 一覧を開き、目的のスライドを選択 |
| 本編・補足 | 「補足へ」「本編に戻る」で切替。本編の末尾から補足へは自動で進まない |
| ノート | 現在のスライドの公開用話者ノートを表示 |
| 出典・共有データ | 出典、共有する条件、使用素材とライセンスを表示 |
| 全画面 | 「全画面」でスライドだけを表示。画面上端へのポインター移動またはTabで操作バーを表示し、「全画面を終了」またはEscで戻る |
| スライドから詳細解説 | 通常表示のスライド末尾にある「文書：…」を選び、対応する章へ移動 |
| 解説からスライドへ | 章末の「スライド：…」で対応するスライドへ移動。スライドから来た場合は「元のスライドへ戻る」で起点へ復帰 |
| 詳細ガイドの目次 | 目的の章を選択。狭い画面では目次を開いて選び、移動後は本文を読む |
| 狭い画面の表・コード | 名前付きの領域を横にスクロール。ページ全体を横へ動かす必要はない |

資料間の移動では、言語、明暗、起点をURLに保持します。詳細ガイドで別の章を読んだ後や、再読み込み・履歴移動の後も、元のスライドへ戻れます。JavaScriptが無効な場合も既定言語の本文と対応箇所への静的リンクは残りますが、明暗や起点を更新する動的な操作は行いません。

**全画面中は詳細解説への関連リンクを表示しません。** 全画面を終了してからリンクを使ってください。終了後も最後に選んだスライドが保たれます。今回の追加で、共通Skillや全画面操作バーは変更していません。

大きい画面の全画面表示ではスライドを拡大し、小さい画面では文字を縮めず縦スクロールで読みます。Fullscreen APIが利用できない、または要求が拒否された場合は理由を通知します。

モニター全体に表示するには、Edgeなどの独立したブラウザーで開いてください。埋め込みプレビューでは、Fullscreen APIが成功してもプレビュー枠内に留まる場合があります。

## 再生成

制作標準は **`github-brand-html-artifacts` 0.5.0-p05.2**、制作環境は **Node.js 22.16.x** です。再生成には同じ版のSkillと、そのlockfileに固定された既存の依存を使います。Skillや依存ライブラリ自体は、このリポジトリには含めていません。

リポジトリのルートで実行する例です。`<NEW_OUTPUT_DIR>` は、親ディレクトリが存在する新しい出力先へ置き換えてください。

```powershell
$skill = Join-Path $HOME '.copilot\skills\github-brand-html-artifacts'
node "$skill\scripts\build.mjs" --input ".\copilot-beginner-agentic\source" --output "<NEW_OUTPUT_DIR>"
node "$skill\scripts\validate.mjs" --input ".\copilot-beginner-agentic\source" --output "<NEW_OUTPUT_DIR>"
```

この入力から `document.html` と `presentation.html` を生成します。検証した両ファイルを同じ公開フォルダーへ配置し、`presentation.html` を、バイトを保持して `index.html` としても配置します。別名コピーの例です。

```powershell
Copy-Item -LiteralPath '.\copilot-beginner-agentic\presentation.html' -Destination '.\copilot-beginner-agentic\index.html'
```

今回の追加では、元のスライド本文・順序・ID・本編と補足の区分・公開ノートを保ったまま、文書24章、対応24組、文書用の図配置、公式出典2件を共通入力へ追加して再生成しています。スライドの出典パネルも共通入力の9件を表示します。本文を変える場合は入力から再生成し、完成HTMLへ直接CSSやJavaScriptを追加しないでください。

埋め込みのフォント・アイコンなどの原文ライセンスと、ロゴの利用条件を保持してください。リポジトリのMIT表記を、埋め込み素材のライセンスの代わりにはしません。

## 確認範囲と制限

今回の資料ペアは、正規生成物との照合、24組のリンク先、元のスライドDOMと公開ノートの保持、通常表示での往復・起点・履歴・再読み込み、JavaScript無効時の移動を確認しています。既存Edgeのheadlessブラウザーで、代表的な明暗と幅、名前付きの表・コード領域の実ホイール横スクロール、実Fullscreen APIの開始・終了・全画面中の移動とノート・終了後の詳細解説への移動も確認しています。

コード例は、保存されたHTMLから取り出した2つの判定例をNode.jsで実行し、説明した6入力の結果を確認しています。仮想アプリの画面、API、保存処理まで検証したという意味ではありません。

Fullscreen APIの開始・終了と、独立したブラウザーでの実機操作は区別します。旧版では独立したChromeでスライドだけの全画面表示を確認していますが、今回のheadless確認を実機確認へ読み替えてはいません。ネイティブなEsc・Tab、実200%ズーム、PDF・印刷は今回の確認済み項目に含めません。

他のOS・ブラウザーで同じ描画を保証するものではありません。製品情報の基準日、出典、条件を確認して利用してください。
