アクセシビリティ、ストレージ、セッションのライフサイクルと復旧Accessibility, storage, session lifecycle, and recovery

キーボードとスクリーンリーダー、ローカル音声入力を使いこなし、ディスク容量とアーカイブ・削除を安全に管理し、固まったセッションから慎重に復旧します。Work confidently with keyboard navigation, screen readers, and local voice input, manage disk space and archive-versus-delete decisions safely, and recover carefully from a stuck session.

Scenario & scope

シナリオと対象範囲Scenario and scope

具体的なシナリオConcrete scenario

キーボードとスクリーンリーダーを中心に作業し、ときどきローカルの音声入力も使う利用者が、アクセシビリティの挙動を確かめつつ、ローカルディスクの使用量を安全に管理し、セッションが固まったりクラッシュしたりしても作業を失わず、機密情報を漏らさずに復旧できる状態を確認します。A user who relies primarily on keyboard navigation and a screen reader, and occasionally uses local voice input, wants to verify accessible behaviors, manage local disk usage safely, and be able to recover from a stuck or crashed session without losing work or exposing sensitive details.

機能の境界Feature boundary

このガイドはキーボード操作と Shift+Tab によるモード切り替え、アクセシブルなタイムスタンプの開示、フォーカスの挙動、スクリーンリーダー向けラベル、ローカルで動く音声入力モデルとマイクの権限、（対応している範囲での）縮小されたモーションとハイコントラスト、低ディスク容量の警告と再利用可能な見積もり、アーカイブと削除の違い、大規模セッションのバックグラウンド読み込み、隠しファイル表示のリスク、再起動・復旧・デバッグログの取り扱いを扱います。スクリーンリーダーや音声認識ソフトそのもののインストールは前提条件として扱い、このガイドの対象外です。まだ実装されていないアクセシビリティ改善を、公式リリースの裏付けなしに「対応済み」と断定することはしません。This guide covers keyboard operation and Shift+Tab mode cycling, accessible timestamp disclosures, focus behavior, screen-reader labels, the locally run voice-dictation model and microphone permission, reduced motion and high contrast where they are actually supported, low-disk-space warnings and reclaim estimates, the difference between archive and delete, large-session background loading, the risk of showing hidden files, and restart, recovery, and debug-log handling. Installing a screen reader or speech-recognition software itself is treated as a prerequisite and is out of scope. This guide does not claim an accessibility improvement exists unless it is backed by a documented official release.

安全上の注意Safety note: /collect-debug-logs や「Share as gist」で収集したデバッグログには機密情報が含まれる可能性があります。共有する前に必ず内容を確認してください。Files タブで隠しファイルの表示を有効にすると .env のような通常は除外されるファイルが見えるようになるため、その内容をプロンプトに貼り付けないよう注意してください。Debug logs collected with /collect-debug-logs or “Share as gist” may contain sensitive information—always review them before sharing. Enabling hidden-file visibility in the Files tab reveals files like .env that are normally excluded, so avoid pasting their contents into a prompt.

Prepare

前提条件Prerequisites

  • テストに使える OS レベルのスクリーンリーダー（Windows の Narrator、macOS の VoiceOver、Linux の Orca など）が利用可能であること。スクリーンリーダー自体のインストール方法はこのガイドでは扱いません。An OS-level screen reader available for testing (for example, Windows Narrator, macOS VoiceOver, or Orca on Linux). Installing the screen reader itself is not covered here.
  • 音声入力を試す場合は、動作するマイクが接続されていること。音声入力は英語またはスペイン語向けの音声認識モデルをローカルにダウンロードする必要があります。A working microphone connected to your machine if you plan to test voice input. Voice input requires downloading a local speech-recognition model for English or Spanish.
  • アーカイブ・削除・再起動を安全に試せる、重要度の低いセッションまたはプロジェクトが少なくとも 1 つ接続されていること。At least one low-stakes session or project connected, so you can safely test archive, delete, and restart without risking real work.
  • Manage sessions の一覧でセッションごとのサイズ（v1.0.18 以降で表示）を確認できる状態であること。ディスク容量に関する手順の前後比較に使います。The Manage sessions table showing per-session size (available since v1.0.18) is accessible, so you can compare disk usage before and after the storage steps.

Hands-on

手順Steps

  1. キーボード操作とモード切り替えを確認するCheck keyboard navigation and mode cycling

    Tab キーだけでプロンプト欄やタイムラインの主要な操作要素に到達できるか確認します。次に Shift+Tab で Interactive・Plan・Autopilot のモードを切り替えます。この挙動は Copilot CLI のプロンプト入力でも共通のものです。Confirm that Tab alone reaches the main controls in the composer and timeline. Then press Shift+Tab to cycle through the Interactive, Plan, and Autopilot session modes—this behavior is shared with Copilot CLI's prompt input.

    フォーカスリングがはっきり見えるかも確認します。ドロップダウンメニューのフォーカスリング表示や、Files ツリー先頭行のフォーカスリングの欠け（クリップ）は過去に修正されています。Also confirm that the focus ring is clearly visible. Focus-ring visibility on dropdown menus and clipping on the first row of the Files tree have both been fixed in past releases.

    モード切り替えのショートカットMode-cycling shortcut 
    Shift+Tab
    期待される結果Expected result: フォーカスがプロンプト欄内の各コントロールを目に見える形で移動し、Shift+Tab を押すたびにフィールドから抜けることなくセッションモードが切り替わります。Focus visibly moves across the controls in the prompt composer, and pressing Shift+Tab reliably cycles the session mode without leaving the field.

  2. アクセシブルなタイムスタンプとラベルを確認するCheck accessible timestamps and labels

    My Work やアクティビティフィードにある相対時間（例:「3時間前」）をキーボードまたはクリックで開き、正確な日時が開示されることを確認します。v1.1.2 では、この開示ボタンがスクリーンリーダーに対して汎用的な「詳細情報」ではなく「タイムスタンプを表示」と読み上げられるようになりました。Activate a relative timestamp (for example, “3h ago”) in My Work or the activity feed with the keyboard or a click, and confirm it discloses the exact date and time. In v1.1.2, this disclosure control announces “show timestamp” to screen readers instead of the generic “more info.”

    サイドバーで現在選択されているビュー（Home、My work、Automations、Extensions）がスクリーンリーダーに読み上げられることも確認します。Also confirm that the currently active sidebar view (Home, My work, Automations, Extensions) is announced by the screen reader.

    期待される結果Expected result: タイムスタンプを開くと正確な日時が表示され、スクリーンリーダーが説明的なラベルを読み上げます。サイドバーの現在のビューも読み上げられます。Activating a timestamp reveals the exact date and time, and the screen reader announces a descriptive label. The current sidebar view is also announced.

  3. 音声入力とマイクの権限を設定するSet up voice dictation and microphone permission

    /voice を実行し、音声認識を支えるランタイムと音声モデル（既定は英語、任意でスペイン語）をダウンロードします。OS からマイクへのアクセス許可を求められたら許可します。文字起こしはローカルで完結し、音声データはネットワークに送信されません。Run /voice to download the runtime and the voice model that power speech recognition (English by default, Spanish optionally). Grant microphone access when the OS prompts you. Transcription happens entirely on your machine, and your audio is never sent over the network.

    短いプロンプトはスペースキーを押し続けている間だけ録音し、長いプロンプトは Ctrl+X の後に V を押してトグル録音を使います。App の音声モードでも、マイクのシステム設定を開く際のクラッシュ修正など、CLI と同じ基盤に対する改善が適用されています。For short prompts, hold the space bar while speaking; for longer prompts, press Ctrl+X followed by V to toggle recording on and off. The app's own voice mode has also received fixes—such as preventing a crash when opening microphone system settings—on the same underlying engine it shares with the CLI.

    音声入力を有効にするEnable voice input 
    /voice
    期待される結果Expected result: 音声モデルのダウンロードが完了し、話した内容がプロンプト欄のカーソル位置にローカルで文字起こしされ、ネットワーク越しの送信なしに挿入されます。The voice model finishes downloading, and speech is transcribed locally and inserted at the cursor position in the prompt field without any network round-trip.

  4. 縮小されたモーションとハイコントラストを確認するCheck reduced motion and high-contrast behavior

    OS レベルでハイコントラストや「動きを減らす」設定を有効にしたうえで App を開き、拡張機能・スキルの行がホバー時の背景に隠れず正しく表示されることを確認します（v1.1.0 で修正済み）。Enable high contrast or “reduce motion” at the OS level, then open the app and confirm extension and skill rows display correctly instead of being hidden behind the hover background in high-contrast mode (fixed in v1.1.0).

    すべての視覚要素に専用の縮小モーション対応があるとは限りません。見つけた挙動を思い込みで「対応済み」と判断せず、変更履歴で裏付けを確認してください。Not every visual element necessarily has a dedicated reduced-motion treatment yet. Don't assume a behavior is “supported” just because you observe it—confirm it against the changelog.

    期待される結果Expected result: ハイコントラストモードで拡張機能・スキルの行が正しく表示され、それ以外に気づいたモーションやコントラストの問題は、思い込みではなく変更履歴と照らし合わせて確認されています。Extension and skill rows display correctly in high-contrast mode, and any other motion or contrast issue you notice is checked against the changelog rather than assumed to be fixed.

  5. 低ディスク容量の警告と再利用見積もりを確認するReview low-disk warnings and reclaim estimates

    サイドバーの低ディスク容量の警告バナーと、Manage sessions にある Copilot セッションストレージの内訳を確認します。セッションを削除する前に表示される「解放される見積もり容量」も確認します。Review the low-disk-space warning banner in the sidebar and the Copilot session storage breakdown in Manage sessions. Also check the estimated amount of space that will be reclaimed, shown before you delete a session.

    期待される結果Expected result: 削除候補のセッションについて、解放される見積もり容量を削除前に確認できます。You can see an estimate of the disk space a candidate session would free, before you delete it.

  6. アーカイブと削除を使い分けるChoose between archive and delete

    テスト用のチャットまたはセッションをアーカイブし、サイドバーからは隠れるものの履歴は残ること、Manage sessions から後で復元できることを確認します。次に不要なローカルセッションを完全に削除し、直前に確認した見積もりに近い容量が解放されることを確認します。Archive a test chat or session and confirm it disappears from the sidebar while its history is preserved and can be restored later from Manage sessions. Then fully delete a disposable local session and confirm the freed space is close to the estimate you checked a moment ago.

    共有されているセッションやクラウドの Copilot cloud agent セッションはアーカイブのみ可能で、削除できるのはローカルセッション（CLI、VS Code、JetBrains、App）だけである点も確認します。Also confirm that shared sessions and Copilot cloud agent sessions can only be archived, while only local sessions (from CLI, VS Code, JetBrains, or the app) can be deleted.

    期待される結果Expected result: アーカイブしたテスト用チャットを Manage sessions から見つけて復元でき、削除したローカルセッションでは見積もりに近い容量が実際に解放されています。The archived test chat can be found and restored from Manage sessions, and deleting the local session freed an amount of space close to the earlier estimate.

  7. 隠しファイルのリスクと大規模セッションの読み込みを確認するCheck hidden-file risk and large-session loading

    Files タブで「隠しファイルを表示」を切り替え、.gitignore で通常は除外される .env のようなファイルが見えるようになることを確認します。表示された内容に機密情報が含まれる可能性があるため、その内容をプロンプトに貼り付けないでください。Toggle “show hidden files” in the Files tab and confirm that files like .env, normally excluded by .gitignore, become visible. Their contents may be sensitive, so don't paste them into a prompt.

    次に、メッセージ数の多い古いセッションを開き、アプリがフリーズせず、古いメッセージがバックグラウンドで読み込まれることを確認します。Then open a large, older session and confirm the app doesn't freeze—older messages should load in the background instead.

    期待される結果Expected result: 隠しファイルは明示的に切り替えたときだけ表示され、大規模セッションはすぐに開いて古いメッセージがバックグラウンドで補完されます。Hidden files are visible only when explicitly toggled on, and the large session opens promptly with older messages populating in the background.

  8. 再起動・復旧・デバッグログを安全に扱うHandle restart, recovery, and debug logs safely

    セッションが固まった場合は「Restart session」の復旧オプションを使います。再起動する前に、未コミットの変更やそのワークスペースにしか存在しないファイルを確認する低リスクなプロンプトを実行しておきます。If a session gets stuck, use the “Restart session” recovery option. Before restarting, run a low-risk prompt that checks for uncommitted changes and files that exist only in that workspace.

    不具合を報告する場合は /collect-debug-logs または「Share as gist」でログを取得しますが、github/app の README が注意しているとおりログには機密情報が含まれる可能性があるため、公開 Issue に添付する前に必ず内容を確認してください。When reporting a bug, gather logs with /collect-debug-logs or “Share as gist,” but—per the github/app README's caution—review the log for sensitive content before attaching it to a public issue.

    再起動前の確認プロンプトPre-restart confirmation prompt 
    Summarize this session's uncommitted changes and tell me which files exist only in this workspace, so I can decide whether it's safe to restart or delete it.
    再起動前の確認プロンプト（日本語）Pre-restart confirmation prompt (Japanese) 
    このセッションの未コミットの変更を要約し、このワークスペースにしか存在しないファイルを教えてください。再起動または削除しても安全かどうかを判断します。
    デバッグログを収集するCollect debug logs 
    /collect-debug-logs
    期待される結果Expected result: 固まったセッションが「Restart session」によって、すでにプッシュ済みのコミットを失うことなく復旧し、共有前にデバッグログの内容を確認済みです。The stuck session recovers via “Restart session” without losing commits already pushed, and the debug log has been reviewed for sensitive content before sharing.

Verify

完了時の確認Completion checks

  • キーボードだけでプロンプト欄の主要な操作要素にすべて到達でき、Shift+Tab で Interactive・Plan・Autopilot を確実に切り替えられる。Keyboard-only navigation reaches every main control in the prompt composer, and Shift+Tab reliably cycles Interactive, Plan, and Autopilot.
  • 少なくとも 1 つのアクセシブルなタイムスタンプ開示と 1 つのスクリーンリーダーラベルを、v1.1.2 の変更履歴の記載と突き合わせて確認できた。At least one accessible timestamp disclosure and one screen-reader label were verified against what the v1.1.2 changelog documents.
  • 音声データをネットワークに送信することなく、マイクの権限を明示的に許可したうえでローカルの音声入力を有効化できた。Voice dictation was enabled locally with an explicit microphone-permission grant, and no audio left the machine.
  • テスト用セッションをアーカイブして復元できたことと、不要なローカルセッションを削除して見積もり通りの容量が解放されたことを確認できた。A test session was successfully archived and restored, and a disposable local session was deleted with disk space freed close to the earlier estimate.
  • 固まったセッションの復旧と、機密情報を確認済みのデバッグログ提供を、隠しファイルの内容を漏らすことなく完了できた。Recovery from a stuck session and a reviewed debug-log submission were both completed without exposing hidden-file contents.

Recover

トラブルシューティングTroubleshooting

Shift+Tab を押してもモードが切り替わらないShift+Tab doesn't seem to change the session mode

他のパネルではなく、プロンプト入力欄にフォーカスがあることを確認してからショートカットを押してください。このモード切り替えの挙動は v1.1.1 で導入されました。Confirm focus is inside the prompt composer, not another panel, before pressing the shortcut. This mode-cycling behavior was introduced in v1.1.1.

音声入力が録音を開始しないVoice input never starts recording

OS がマイクへのアクセスをアプリに許可しているか確認し、/voice devices で使用中の入力デバイスを確認します。言語を切り替えた場合は該当する音声モデルを再ダウンロードしてください。Confirm the OS has granted microphone access to the app, and check the active input device with /voice devices. If you switched languages, re-download the corresponding voice model.

Files タブで隠しファイルを表示にしても一部のファイルが表示されないSome files stay hidden even after enabling “show hidden files”

このトグルは .gitignore で除外されているファイルを表示するためのものです（v1.1.1 で追加）。別の仕組みで除外されているファイルは対象外の場合があるため、別途確認してください。This toggle reveals files excluded by .gitignore rules (added in v1.1.1). Files excluded by a different mechanism may not be affected, so check separately.

セッションを削除しても見積もりほどディスク容量が解放されないDeleting a session doesn't free as much space as estimated

見積もりはローカルの成果物に対するおおよその値です。共有セッションやクラウド同期されたセッションデータはローカル削除の影響を受けません。共有セッションや Copilot cloud agent のセッションはアーカイブのみ可能で、削除はできない点も確認してください。The estimate approximates local artifacts only. Shared or cloud-synced session data isn't affected by a local delete. Also remember that shared sessions and Copilot cloud agent sessions can only be archived, not deleted.

セッションの再開が繰り返し固まるResuming a session gets permanently stuck

v1.0.26 で追加された「Restart session」オプションを使います。それでも解決しない場合は、デバッグログを収集して機密情報を確認したうえで、OS・バージョン・再現手順を添えて Issue を報告してください。Use the “Restart session” option added in v1.0.26. If the problem persists, collect debug logs, review them for sensitive content, and file an issue with your OS, version, and reproduction steps.

Reset

クリーンアップとリセットCleanup and reset

  1. アクセシビリティやストレージの動作確認だけのために作成したセッションは、共有されていないローカルなものに限ってアーカイブまたは削除します。Archive or delete any sessions created solely to verify accessibility or storage behavior, choosing delete only for unshared, local sessions.
  2. この手順のためだけに「隠しファイルを表示」を有効にした場合は、元に戻して .env のようなファイルを既定どおり非表示にします。If you enabled “show hidden files” only for this exercise, turn it back off so files like .env stay hidden by default.
  3. テストのために作成したデバッグログの gist やファイルは、機密情報が含まれていないことを確認したうえで削除するか、含まれていた場合は速やかに削除します。Delete the debug-log gist or file you created for testing once you've confirmed it contains nothing sensitive, or remove it immediately if it does.
  4. この手順のためだけに変更した OS レベルのアクセシビリティ設定（縮小されたモーション、ハイコントラスト、スクリーンリーダーなど）が普段の作業環境と異なる場合は元に戻します。Revert any OS-level accessibility settings (reduced motion, high contrast, screen reader, and so on) you changed only for this test if they don't match your normal working setup.

Platforms

プラットフォーム別の注意Platform-specific notes

Windows

Narrator と Windows のハイコントラストテーマの組み合わせで確認するのが基本です。低ディスク容量バナーはアプリデータが置かれている Windows のボリュームを対象とし、Files タブの隠しファイル表示はエクスプローラー自体の設定とは独立しています。Narrator paired with a Windows high-contrast theme is the natural combination to test with. The low-disk-space banner reads the Windows volume where app data lives, and the Files tab's hidden-file toggle is independent of Windows Explorer's own setting.

macOS

VoiceOver 向けの読み上げ修正（オンボーディングの「setting up」画面など、v1.1.0 で修正）が該当します。音声入力のダウンロードは CLI と同じローカルモデルの仕組みを使います。アクセシビリティ用のキーボードショートカットと、改行を挿入する Option+Enter を混同しないよう注意してください。VoiceOver-specific announcement fixes apply here (for example, the onboarding “setting up” screen, fixed in v1.1.0). Voice-input downloads use the same on-device model mechanism as the CLI. Be careful not to confuse your accessibility shortcuts with Option+Enter, which inserts a newline.

Linux

確認を始める前に、ディストリビューションのスクリーンリーダー（Orca など）とシステムのコントラストテーマが有効になっていることを確認してください。AppImage の実行権限設定はアプリ内のアクセシビリティ設定に影響しません。Before testing, confirm your distribution's screen reader (such as Orca) and system contrast theme are active. AppImage execute-permission settings don't affect in-app accessibility settings.

WSL

WSL 内のリポジトリを扱う場合でも、App 自体は常に Windows 側で動作します（ガイド 01 参照）。そのためアクセシビリティ設定、音声入力、ローカルディスク容量の見積もりはすべて Windows 側のインストールが基準になり、WSL 側のファイルシステムにはコードとその使用容量だけが存在します。Even when working on a WSL-hosted repository, the app itself always runs on the Windows side (see guide 01). So accessibility settings, voice input, and local disk-space estimates are all governed by the Windows install; only the code and its own disk usage live inside the WSL filesystem.
