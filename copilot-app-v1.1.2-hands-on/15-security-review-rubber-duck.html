セキュリティレビューとラバーダックで批評を受けるGet a critique with security review and rubber duck

/security-review で高信頼度の脆弱性を確認し、Claude または GPT を使うセッションではラバーダックエージェントから建設的な批評を受けます。どちらも既存のセキュリティ機能を置き換えるものではありません。Use /security-review to surface high-confidence vulnerabilities, and get a constructive critique from the rubber duck agent when your session uses a Claude or GPT model. Neither replaces your existing security tools.

Scenario & scope

シナリオと対象範囲Scenario and scope

具体的なシナリオConcrete scenario

PR を出す前に、進行中のセッションで /security-review を実行して認証やシークレット周りの高信頼度の指摘を確認し、続けてラバーダックエージェントに実装計画への批評を依頼して、コードスキャンや Dependabot に頼る前の一次チェックとします。Before opening a PR, you run /security-review in an active session to catch high-confidence findings around auth and secrets, then ask the rubber duck agent to critique your implementation plan as an initial check before relying on code scanning and Dependabot.

機能の境界Feature boundary

このガイドは進行中のセッション内での /security-review とラバーダックエージェントの使い方を扱います。コードスキャン、Dependabot、シークレットスキャン自体の設定は対象外です。これらは既存の仕組みを補完するものであり、置き換えるものではありません。This guide covers using /security-review and the rubber duck agent inside an active session. Configuring code scanning, Dependabot, or secret scanning themselves is out of scope. Both features complement, rather than replace, those existing tools.

安全上の注意Safety note: /security-review はパブリックプレビューであり、すべての脆弱性を検出することを保証しません。ラバーダックエージェントの批評は建設的な意見であり、セキュリティ上の保証ではありません。本番リリース前には、コードスキャン、Dependabot、シークレットスキャンなど既存の仕組みによる確認を必ず継続してください。/security-review is in public preview and does not guarantee detection of all vulnerabilities. The rubber duck agent's critique is a constructive opinion, not a security guarantee. Continue to rely on code scanning, Dependabot, and secret scanning before any production release.

Prepare

前提条件Prerequisites

  • ガイド 13 を完了し、レビュー対象の変更を含むアクティブなセッションを開けること。Guide 13 is complete and you can open an active session containing the changes to review.
  • セッションのメインエージェントが Claude または GPT 系のモデルに設定されていること (ラバーダックエージェント利用の条件)。The session's main agent is configured to use a Claude- or GPT-family model, a requirement for the rubber duck agent.
  • 対象リポジトリで、コードスキャン、Dependabot、シークレットスキャンなど既存のセキュリティ機能がどのように設定されているか把握していること。You understand how existing security features such as code scanning, Dependabot, and secret scanning are configured in the target repository.

Hands-on

手順Steps

  1. 変更途中のアクティブなセッションを開くOpen an active session with in-progress changes

    レビューしたい差分がまだ含まれているセッションを開きます。Open the session that still contains the diff you want to review.

    期待される結果Expected result: セッションの Changes に、レビュー対象の差分が表示されています。The session's Changes shows the diff you intend to review.

  2. /security-review を実行するRun /security-review

    プロンプトボックスに /security-review と入力して実行します。Type /security-review in the prompt box and run it.

    /security-review を実行Run /security-review 
    /security-review
    期待される結果Expected result: 重要度と信頼度スコア付きの指摘と、適用可能な修正案が返ります。You get findings with severity and confidence scores, plus suggested fixes you can apply.

  3. 指摘を確認し、必要なら修正を適用するReview findings and apply fixes if needed

    高信頼度の指摘に対応し、同じセッション内で修正結果を検証します。Address the high-confidence findings and verify the fix in the same session.

    期待される結果Expected result: 指摘された高信頼度の問題が修正され、セッション内で検証できます。The high-confidence issues are fixed and verified in the session.

  4. セッションのモデルが Claude または GPT であることを確認するConfirm the session's model is Claude or GPT

    モデルピッカーで現在のモデルを確認します。ラバーダックエージェントは Claude または GPT 系モデルのときにのみ利用できます。Check the current model in the model picker. The rubber duck agent is only available with a Claude- or GPT-family model.

    期待される結果Expected result: ラバーダックエージェントが利用可能な状態であることが確認できます。You confirm the rubber duck agent is available for this session.

  5. /rubber-duck で批評を依頼するAsk for a critique with /rubber-duck

    実装計画やコードについて具体的な観点を挙げて批評を依頼します。Ask for a critique of your plan or code, naming a specific aspect you want scrutinized.

    /rubber-duck で批評を依頼Ask for a critique with /rubber-duck 
    /rubber-duck Critique my current implementation plan for the auth middleware change, focusing on blind spots and edge cases.
    期待される結果Expected result: セッションとは別のモデルによる、blocking / non-blocking / suggestion に分類された建設的な批評が返ります。You receive a constructive critique from a different model, categorized as blocking, non-blocking, or a suggestion.

  6. 批評を踏まえて計画または実装を調整するAdjust the plan or implementation based on the critique

    blocking の指摘には必ず対応し、その後もコードスキャンなど既存の仕組みでの確認を継続します。Address any blocking findings, and continue to rely on existing tools such as code scanning afterward.

    期待される結果Expected result: 重大な指摘に対応し、既存のセキュリティ機能による確認プロセスは変わらず継続されています。Blocking findings are addressed, and your existing security review process continues unchanged.

Verify

完了時の確認Completion checks

  • /security-review が現在の差分に対して重要度・信頼度付きの指摘を返した。/security-review returned findings with severity and confidence for the current diff.
  • セッションのモデルが Claude または GPT のときに、ラバーダックエージェントの批評を受け取れた。You received a critique from the rubber duck agent while the session's model was Claude or GPT.
  • 批評が blocking / non-blocking / suggestion に分類され、行動可能な内容だった。The critique was categorized as blocking, non-blocking, or a suggestion, and was actionable.
  • コードスキャン、Dependabot、シークレットスキャンなど既存の仕組みを置き換えていないことを確認できた。You confirmed that neither feature replaces existing tools like code scanning, Dependabot, or secret scanning.

Recover

トラブルシューティングTroubleshooting

/security-review を実行しても何も見つからないと表示される/security-review reports no findings

指摘がない場合は明示的にその旨が返されます。パブリックプレビューのため検出範囲には限りがあるので、コードスキャンなど既存の仕組みでの確認も継続してください。When there are no findings, the command explicitly says so. Because this is a public preview, coverage is limited, so continue relying on existing tools like code scanning.

/rubber-duck を実行しても批評が返らない/rubber-duck doesn't return a critique

セッションのメインエージェントが Claude または GPT 系モデルになっているか確認してください。他のモデルの場合、ラバーダックエージェントは現在利用できません。Check that the session's main agent is using a Claude- or GPT-family model. The rubber duck agent is not currently available with other models.

ラバーダックの指摘がスタイルや命名など些末な内容ばかりに見えるThe rubber duck's feedback seems limited to style or naming nitpicks

ラバーダックエージェントはスタイル、フォーマット、命名規則などを意図的にコメントしないよう設計されています。的外れに見える場合は、批評してほしい計画や実装をより具体的に説明して再依頼してください。The rubber duck agent is deliberately designed not to comment on style, formatting, or naming conventions. If the feedback seems off-target, describe the plan or implementation you want critiqued more specifically and ask again.

Reset

クリーンアップとリセットCleanup and reset

  1. セキュリティレビューで適用したテスト用の修正が不要であれば、Changes から取り消します。Revert any test fixes you applied during the security review from Changes if they aren't needed.
  2. 批評のために操作したセッションをアーカイブまたは削除します。Archive or delete the session you used for the critique.
  3. 本番リリース前に、コードスキャン、Dependabot、シークレットスキャンの結果も別途確認したことを記録します。Before any production release, record that you separately checked the results of code scanning, Dependabot, and secret scanning.

Platforms

プラットフォーム別の注意Platform-specific notes

Windows

Windows でもスラッシュコマンドの挙動は同一です。日本語入力中は変換確定後に / を入力してください。Slash command behavior is identical on Windows. When using Japanese IME input, type / after confirming conversion.

macOS

macOS でも同様にプロンプトボックスへ直接スラッシュコマンドを入力します。On macOS, type the slash command directly into the prompt box the same way.

Linux

Linux の AppImage ビルドでも /security-review と /rubber-duck は同一のセッション機能として動作します。On the Linux AppImage build, /security-review and /rubber-duck work the same way as session features.

WSL

WSL リモート環境のセッションでもこれらのスラッシュコマンドは同様に使えます。表示は Windows 側アプリのウィンドウで行われます。These slash commands work the same way in WSL remote environment sessions. Output is displayed in the Windows-side app window.
