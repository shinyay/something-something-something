Session Grid とサイドチャットで複数セッションを俯瞰するOversee multiple sessions with Session Grid and side chats

v1.1.0で全ユーザーに提供されたSession Gridで複数セッションを同時に表示し、レビューパネルのサイドチャットで文脈を保ったまま質問し、プルリクエストタイトルへの自動セッション名変更を確認します。Use Session Grid, available to all users since v1.1.0, to view multiple sessions at once, ask scoped questions with side chats in the review panel, and confirm automatic session renaming to the pull request title.

Scenario & scope

シナリオと対象範囲Scenario and scope

具体的なシナリオConcrete scenario

3つの独立した小さな修正セッションを同時に走らせながらSession Gridで進捗を横並びに確認し、そのうち1つのセッションからプルリクエストを作成してセッション名がタイトルに合わせて変わることを確認します。さらにそのPRのレビューパネルでサイドチャットを開き、差分について質問します。Run three independent small-fix sessions at once, watch their progress side by side in Session Grid, create a pull request from one of them and confirm its session name updates to match the PR title, then open a side chat in that PR's review panel to ask a scoped question about the diff.

機能の境界Feature boundary

このガイドは GitHub Copilot App のSession Grid、サイドチャット、自動セッション名変更というUI機能を扱います。これらはv1.1.0で全ユーザーに提供された機能であり、Copilot CLIのマルチセッション機能とは別物です。CLI側で同等の並列表示を行いたい場合は、Copilot CLIの公式ドキュメントを参照してください。This guide covers the GitHub Copilot app's Session Grid, side chats, and automatic session renaming UI features. These became available to all users in v1.1.0 and are distinct from any multi-session capability in Copilot CLI. If you want an equivalent parallel view from the CLI, consult Copilot CLI's own official documentation.

安全上の注意Safety note: サイドチャットで差分について質問する際、.envなどの秘密情報を含むファイルの内容をそのまま貼り付けないでください。プロンプトや共有スクリーンショットにシークレットを含めないよう注意します。When asking about a diff in a side chat, don't paste the contents of files that hold secrets, such as .env. Be careful not to include secrets in prompts or shared screenshots.

Prepare

前提条件Prerequisites

  • 同時に進行できる独立した小さなタスクが3つ以上あること（サンプルリポジトリの軽微な修正で構いません）。At least three independent small tasks you can run at the same time (minor sample-repository fixes are fine).
  • プルリクエストを作成できるサンプルリポジトリがプロジェクトとして接続済みであること。A sample repository where you can open pull requests is already connected as a project.
  • Settingsでこの機能がオフになっていないこと（デフォルトはオン）。This feature isn't turned off in Settings (it's on by default).

Hands-on

手順Steps

  1. Session Gridが有効になっていることを確認するConfirm Session Grid is enabled

    Settingsを開き、Session Grid/サイドチャット/自動リネームのトグルがオンになっていることを確認します。Open Settings and confirm the Session grid/side chats/auto-rename toggle is on.

    期待される結果Expected result: トグルが既定の有効状態（オン）で表示されます。The toggle shows its default enabled state.

  2. 3つのセッションを開始するStart three sessions

    同じプロジェクトで、修正セッションA・B・Cのプロンプトを使って3つの独立したセッションを開始します。In the same project, start three independent sessions using the fix A/B/C prompts.

    修正セッションAFix session A 
    Fix an obvious typo in this repository's README and open a small, focused diff. Do not touch other files.
    修正セッションBFix session B 
    Add one missing punctuation mark or fix one broken link in this repository's docs, and keep the diff minimal.
    修正セッションCFix session C 
    Improve one unclear code comment in the smallest source file in this repository, without changing behavior.
    期待される結果Expected result: サイドバーのプロジェクトの下に3つのセッションが表示されます。Three sessions appear in the sidebar under the project.

  3. Session Gridを開くOpen Session Grid

    複数セッションを同時に表示するグリッドビューの操作を使い、少なくとも2つのセッションを並べて表示します。Use the control that shows multiple sessions at once, and display at least two sessions side by side.

    期待される結果Expected result: 少なくとも2つのセッションがグリッドレイアウトで同時に表示されます。At least two of the three sessions are visible simultaneously in a grid layout.

  4. セッションからプルリクエストを作成するCreate a pull request from a session

    3つのうち1つのセッションで「Create PR」を実行します。In one of the three sessions, run "Create PR".

    期待される結果Expected result: PRが作成され、そのセッションの名前がPRタイトルに合わせて自動的に変わります。The PR is created, and the session's name automatically updates to match the PR title.

  5. レビューパネルでサイドチャットを開始するStart a side chat in the review panel

    作成したPRのレビューパネルを開き、サイドチャットを開始します。Open the review panel for the pull request you created and start a side chat.

    期待される結果Expected result: サイドチャットがレビューパネル内に開き、メインのセッション会話とは別の文脈として扱われます。The side chat opens within the review panel, treated as a separate context from the main session conversation.

  6. サイドチャットで差分について質問するAsk about the diff in the side chat

    side-chat-questionのプロンプトを送り、差分のどこが実際の動作変更でどこが書式変更かを尋ねます。Send the side-chat-question prompt asking which lines are behavior changes versus formatting only.

    サイドチャットでの質問Side chat question 
    In this pull request's diff, which lines changed behavior versus which are purely formatting? Do not suggest new changes yet.
    サイドチャットでの質問（日本語）Side chat question (Japanese) 
    このプルリクエストの差分のうち、どの行が実際の動作を変えていて、どの行が書式だけの変更ですか。まだ新しい変更は提案しないでください。
    期待される結果Expected result: エージェントがサイドチャット内で回答し、レビューパネルを離れたり新しいトップレベルセッションを作成したりしません。The agent answers within the side chat, without leaving the review panel or creating a new top-level session.

  7. トグルのオン/オフを確認するConfirm the on/off toggle

    Settingsで機能をいったんオフにし、新しいPRを作成してもセッション名が変わらないことを確認してから、再度オンに戻します。Turn the feature off in Settings and confirm a new PR no longer renames the session, then turn it back on.

    期待される結果Expected result: オフの間はセッション名が自動で変わらず、オンに戻すとリネームが再開します。While off, the session name doesn't auto-rename; turning it back on resumes renaming.

Verify

完了時の確認Completion checks

  • 少なくとも2つのセッションをSession Gridで同時に表示できた。At least two sessions were visible at once in Session Grid.
  • プルリクエストを作成したセッションの名前がPRタイトルに自動的に変わった。The session's name automatically changed to match the pull request title after creating it.
  • レビューパネルのサイドチャットで質問しても、メインのセッション会話には影響しなかった。Asking a question in the review panel's side chat did not affect the main session conversation.

Recover

トラブルシューティングTroubleshooting

Session Gridの表示切り替えが見当たらないCan't find the control to switch to Session Grid

Settingsでこの機能がオフにされていないか確認してください。v1.1.0以降は全ユーザーに提供されていますが、個別にオフにできます。Check whether the feature was turned off in Settings — it's available to all users since v1.1.0, but can be disabled individually.

PR作成後もセッション名が変わらないThe session name doesn't change after creating a PR

自動リネームがSettingsでオフになっていないか確認します。オンでも一度手動でリネームした後は自動更新されない場合があります。Confirm automatic renaming isn't disabled in Settings. Also note that once you manually rename a session, it may no longer auto-update.

サイドチャットの内容がメインセッションに紛れ込んだように見えるSide chat content seems to bleed into the main session

サイドチャットはレビューパネル専用の会話です。メインのセッションタブに戻り、会話が分離されているか確認してください。混同する場合はサイドチャットを開き直します。A side chat is a conversation scoped to the review panel. Switch back to the main session tab to confirm the conversations are separate, and reopen the side chat if it seems mixed up.

Reset

クリーンアップとリセットCleanup and reset

  1. 3つのデモセッションのうち不要なものをアーカイブまたは削除します。Archive or delete any of the three demo sessions you no longer need.
  2. デモ用に作成したプルリクエストは、必要なければクローズしてブランチを削除します。Close the demo pull request and delete its branch if you don't need to keep it.
  3. Settingsで意図せずオフにした機能を元の状態に戻します。Restore any setting you toggled off during the exercise back to its original state.

Platforms

プラットフォーム別の注意Platform-specific notes

Windows

Windowsでは複数セッションをSession Gridで並べるとウィンドウサイズによってタイル数が変わります。高解像度ディスプレイだと見やすくなります。On Windows, the number of tiles Session Grid shows depends on your window size; a high-resolution display makes it easier to read.

macOS

macOSでも同様にウィンドウサイズに応じてグリッドのタイル数が変わります。フルスクリーンで使うと複数セッションが見やすくなります。On macOS, the grid's tile count also scales with window size; using full screen makes multiple sessions easier to read.

Linux

LinuxのAppImageビルドでも同じグリッド機能が使えます。ウィンドウマネージャーによっては最大化のショートカットが異なります。The same grid feature works on the Linux AppImage build; the maximize shortcut may differ depending on your window manager.

WSL

WSL上のリポジトリでもSession Gridとサイドチャットは同じUIで動作します。App自体はWindows側にインストールされたままです。Session Grid and side chats work the same way for repositories inside WSL. The app itself remains installed on the Windows side.
