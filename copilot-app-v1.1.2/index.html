Workflow

代表的なエンドツーエンドフローA representative end-to-end workflow

  1. My Work で対象を絞るFind the work in My Work

    Issue、プルリクエスト、CI 状態を検索条件で整理し、次に扱う 1 件を選びます。Organize issues, pull requests, and CI state with filters, then choose one item.

  2. 実行場所と自律性を選ぶChoose execution and autonomy

    worktree、ローカル、クラウドの実行場所と Interactive、Plan、Autopilot をリスクに合わせて選びます。Match worktree, local, or cloud execution and Interactive, Plan, or Autopilot to the risk.

  3. 並列セッションを監督するSupervise parallel sessions

    Session Grid、サイドチャット、Files、Changes、Canvas で複数の進捗と成果を確認します。Use Session Grid, side chats, Files, Changes, and Canvas to inspect several streams and artifacts.

  4. レビューと CI を通すComplete review and CI

    差分とコメントを確認し、必要なら security review や rubber duck を使い、ブロッカーを解消します。Review diffs and comments, optionally use security review or rubber duck, and resolve blockers.

  5. GitHub の条件を満たして着地するLand after GitHub requirements pass

    必須レビュー、ブランチ保護、CI、マージキューの条件を尊重して Agent Merge または手動でマージします。Respect required reviews, branch protection, CI, and merge-queue conditions, then use Agent Merge or merge manually.

Setup

導入の最短手順Shortest setup path

  1. 公式ダウンロードから OS とアーキテクチャに合うビルドを入手します。Download the build for your OS and architecture from the official page.
  2. GitHub にサインインします。GHES では GitHub Enterprise を選びます。Sign in to GitHub; choose GitHub Enterprise for GHES.
  3. Copilot seat または独自モデルプロバイダーを選びます。キーは資格情報欄だけに入力します。Choose a Copilot seat or an external model provider; enter keys only in credential fields.
  4. GitHub リポジトリ、ローカルフォルダー、または Git URL をプロジェクトとして追加します。Add a GitHub repository, local folder, or Git URL as a project.
  5. 低リスクの探索を Plan または Interactive で開始し、Changes を確認します。Start a low-risk exploration in Plan or Interactive and inspect Changes.
  6. 必要なポリシーと実行場所を確認してから Autopilot、cloud、automations へ広げます。Confirm policies and execution boundaries before expanding to Autopilot, cloud, or automations.

モデル、Auto、推論量、BYOK、WSL、CloudModels, Auto, reasoning, BYOK, WSL, and cloud

Auto と既定モデルAuto and the default model

Auto はタスクの複雑さに基づいてモデルを選び、応答ごとの実モデルを表示します。v1.1.2 では既定選択がアカウントで実際に利用可能なモデルに一致します。Auto chooses based on task complexity and shows the model used for each response. In v1.1.2, the default matches models actually available to the account.

推論量Reasoning effort

複雑さに合わせて推論量を選びます。v1.1.2 ではセッション再開やアプリ再起動後も選択が保持されます。Match reasoning effort to complexity. v1.1.2 preserves the choice across session resume and app restart.

Scope discipline

App リリースと隣接機能を区別するDistinguish App releases from adjacent capabilities

このサイトのバージョン差分は github/app の changelog だけを App リリース事実として扱います。Copilot CLI、SDK、cloud agent、sandbox は App と連携する場合でも、それぞれの公式文書で提供範囲を示し、特定 App バージョンの追加機能としては扱いません。This site treats only the github/app changelog as evidence of version-bound App changes. Copilot CLI, SDK, cloud agent, and sandbox capabilities are scoped through their own official documentation, even when they integrate with the App, and are not attributed to an App release without changelog support.
